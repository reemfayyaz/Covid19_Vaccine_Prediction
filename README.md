# 💉 COVID-19 Vaccine Prediction

A Machine Learning web application built with **Streamlit** that
predicts whether a person is likely to accept a COVID-19 vaccine based
on demographic and health-related information.

------------------------------------------------------------------------

## 📌 Features

-   Simple and user-friendly interface
-   Machine Learning prediction using a trained Random Forest model
-   Real-time prediction
-   Displays prediction probabilities
-   Ready for GitHub and Streamlit Cloud deployment

------------------------------------------------------------------------

## 📥 Installation

``` bash
pip install -r requirements.txt
```

------------------------------------------------------------------------

## ▶️ Run the Application

``` bash
streamlit run app.py
```

------------------------------------------------------------------------

## 📊 Input Features

-   Age
-   Gender
-   State
-   Chronic Disease
-   Previous COVID-19 Infection
-   Trust in Vaccine
-   Fear of Side Effects
-   Vaccine Type Preference

------------------------------------------------------------------------

## 🎯 Output

The application predicts whether a person is likely to accept the
COVID-19 vaccine (**Yes** or **No**).
